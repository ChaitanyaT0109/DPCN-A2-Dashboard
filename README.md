# DPCN A2: Team 12 dashboard

Interactive dashboard for DPCN Assignment 2, Team 12: research mapping of **NIT Trichy** and **NIT Surathkal**.

**Live dashboard:** https://chaitanyat0109.github.io/DPCN-A2-Dashboard/

The dashboard is a single self-contained page (`index.html`). It needs an internet connection to load the chart
libraries (Chart.js, Cytoscape.js) and fonts.
